# Proyecto: Evolución de la Web (React + Vite)
**Estudiante:** Jonathan Morales  
**Facultad:** Informática, Electrónica y Comunicación  
**Materia:** Gerencia de Comercio Electrónico / Animación Web  

## 🚀 Descripción del Proyecto
Este proyecto es una aplicación interactiva desarrollada con **React** que ilustra la transición tecnológica de la World Wide Web. Utiliza un sistema de navegación basado en estados para mostrar las características de cada era.

## 🛠️ Tecnologías Utilizadas
- **React.js & Vite:** Para una estructura modular y carga rápida.
- **Hooks (useState):** Gestión del renderizado condicional para navegar entre la Web 1.0, 2.0 y 3.0.
- **Hooks (useEffect):** Simulación de procesos asíncronos y asincronía de IA en la Web 3.0.
- **CSS-in-JS:** Estilos dinámicos para diferenciar visualmente cada etapa.

## 🧩 Componentes Principales
1. **Web 1.0 (Estática):** Muestra el concepto de "Solo lectura" con contenido fijo.
2. **Web 2.0 (Social):** Implementa un sistema de comentarios funcional para demostrar la interactividad.
3. **Web 3.0 (Inteligente):** Simula una respuesta de IA tras un tiempo de espera (`setTimeout`), representando la web semántica.

## 📂 Cómo ejecutar localmente
1. Clonar el repositorio.
2. Ejecutar `npm install` para instalar dependencias.
3. Ejecutar `npm run dev` para iniciar el servidor de desarrollo.
